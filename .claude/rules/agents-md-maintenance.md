# エージェント指示ファイルの更新ルール

実体は `AGENTS.md` で、`CLAUDE.md` はそこへの symlink である。編集先は AGENTS.md になる。

## 原則

判定は `doc-hygiene.md` に従う。ここは AGENTS.md に何を書くかを持つ。
数値は毎リクエスト context に載る媒体として `doc-hygiene.md` より厳しく、下記に従う (ADR-0001)。

## 書くべきもの

- Claude が推測できないコマンドやワークフロー
- デフォルトと異なるコード規約
- プロジェクト固有の落とし穴・制約
- コミットルールやブランチ運用などの運用規約。テンプレート由来のものは置かず、利用する側が自分のものを足す

## 書くべきでないもの

- コードや設定ファイルから読み取れる情報
- 言語・フレームワークの標準的な慣習
- 一回限りのセットアップ手順
- TODO・ステータス・進捗
- 実測値の詳細 (テスト件数・所要時間・違反件数)。判断を決める閾値だけ書き、根拠の実測は ADR へ置く (ADR-0001)

## サイズ制限

- 50 行以下を目標、100 行を上限
- 数えるのは手書きの行だけ。ツールが管理するマーカー区間 (`<!--VITE PLUS START-->` 〜 `END` 等) は数えない。区間の中身はツールが書き戻すため削れず、上限の対象にすると守れない規約になる
- 超えそうなら `.claude/rules/` に分離する (`paths` フロントマターで必要時のみロードされる)
