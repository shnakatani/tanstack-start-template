# ADR-0034: `src/styles.css` の乖離は、この表の行に限る

- Status: Accepted
- Date: 2026-09-21
- 関連: ADR-0025 (baseline との 3-way による判別)、ADR-0033 (トークンの値を決める規則)

## Context

`src/styles.css` の baseline は `docs/registry-baseline/styles.css` に置く。`shadcn add` は出力しないため、作り直す手順は ADR-0033「土台は空ファイルへの生成物とし、自作分を載せ直す」 が持つ。

## Decision

**`src/styles.css` の生成物からの乖離は、下の表の行に限る。**

`src/styles.css` と `docs/registry-baseline/styles.css` の差分がこの表と 1:1 で対応する。
トークンの値を決める規則は ADR-0033 が持ち、本表は何を動かしたかと、いつ戻せるかを持つ。
表に出る比率は 2026-09-21 の実測で (生成物は `shadcn@4.21.0`)、測り方は ADR-0033 の Context にある。

| 対象                                                       | 乖離                                                                                                                                                                                     | 理由                                                                                                                                                                                                                                                                                                                    | 撤去条件                                                                                         |
| ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `--destructive-surface`                                    | 生成物に無い。light `red-600` / dark `red-400` を足し、`@theme inline` へ `--color-destructive-surface` を通す。値は生成物の `--destructive` と同じ                                      | tint の面と、その上に載る文字を 1 つのトークンで兼ねると、両方を満たす段が無い。面をここへ切り、文字は `--destructive` の名前を保つ (ADR-0033「1 つのトークンが用途を兼ねて両立しないときは、狭い側を別トークンへ切る」)                                                                                                | 上流が面と文字を分けたら撤去。ガードは `contrast.stories.tsx` の axe                             |
| `--success`                                                | 生成物に無い。light `green-800` / dark `green-500` を足し、`@theme inline` へ `--color-success` を通す                                                                                   | 上流は成功のトークンを持たない。消費者はいま `toast.tsx` の `aria-hidden` なアイコン 1 つだが、`@theme inline` へ通すと `text-success` が生える。既定として配る以上、本文へ使っても割らない段を採る。`--background` の上で緑の既定に近い `green-600` は 3.22 で届かず、`green-800` は 7.13、dark の `green-500` は 8.89 | 上流が成功のトークンを持ったら撤去。消費者は `toast.tsx` の成功アイコン                          |
| `--placeholder`                                            | 生成物に無い。light dark とも `mist-500` を `:root` へ足し、`@theme inline` へは通さず `@utility example-placeholder` だけで露出させる。light の値は生成物の `--muted-foreground` と同じ | `::placeholder` の例示テキスト専用に切った。`--muted-foreground` を `mist-600` へ下げると例示が入力値と紛れる。`select` の `data-placeholder:` は実テキストなので対象外 (ADR-0035)                                                                                                                                      | 上流が例示専用のトークンを持ったら撤去。この色を見るガードは無い (ADR-0035)                      |
| `--primary`                                                | light を `blue-800`、dark を `blue-300` へ                                                                                                                                               | light と dark で面と文字の役割を反転させる (ADR-0033「有彩色のアクセントは light と dark で役割を反転させる」)。生成物は dark の `text-primary` が 2.23、light の `bg-primary/80` が 4.21                                                                                                                               | 上流が `text-primary` と solid と `/80` の 3 役すべてを満たす段を選んだら撤去                    |
| `--primary-foreground`                                     | dark を `blue-950` へ                                                                                                                                                                    | 反転させた dark の `--primary` に載せる文字。solid の上で 8.15                                                                                                                                                                                                                                                          | 同上                                                                                             |
| `--sidebar-primary` / `--sidebar-primary-foreground`       | `--primary` の対と同じ段へ                                                                                                                                                               | 上流は sidebar だけ別の段を使い、dark の対が 3.45 で閾値を割る (ADR-0033「有彩色のアクセントは light と dark で役割を反転させる」)                                                                                                                                                                                      | 同上                                                                                             |
| `--muted-foreground`                                       | light を `mist-600` へ                                                                                                                                                                   | 生成物の `mist-500` は `--muted` の上で 4.13 と 4.5:1 を割る                                                                                                                                                                                                                                                            | 上流が base color 全色で 4.5:1 を満たす段を選んだら撤去                                          |
| `--destructive`                                            | light を `red-800`、dark を `red-300` へ                                                                                                                                                 | tint の上の文字として使う段へ下げる。面は `--destructive-surface` が持つ (ADR-0033「1 つのトークンが用途を兼ねて両立しないときは、狭い側を別トークンへ切る」)                                                                                                                                                           | 上流が面と文字を分けたら撤去。ガードは `contrast.stories.tsx` の axe                             |
| `--ring` / `--sidebar-ring`                                | `--primary` と同値へ                                                                                                                                                                     | 生成物の `mist-400` は `--background` の上で light 2.44。不透明で使う `border-ring` / `outline-ring` が 3:1 を超える                                                                                                                                                                                                    | 上流が 3:1 を満たす値を選んだら撤去。`ring-ring/50` に残る不足は ADR-0033 の Consequences が持つ |
| `@import "tailwindcss" source("../src")`                   | 生成物は `source()` を持たない                                                                                                                                                           | scan の既定はリポジトリ全体で、Markdown の字面まで本番 CSS へ出る (ADR-0056)                                                                                                                                                                                                                                            | —                                                                                                |
| `@theme` の palette 除去ブロック                           | 生成物に無い。`--color-*: initial` で既定 palette を消し、`--color-black` / `--color-white` だけ残す                                                                                     | 色を semantic token だけに通し、`bg-red-500` のような palette utility を CSS ごと消す。黒白を残すのは registry の overlay が `bg-black/10` で scrim を描くため                                                                                                                                                          | —                                                                                                |
| `@theme inline` の直前の注記コメント                       | 生成物に無い。`theme(static)` を本番側へ付けない旨を置く                                                                                                                                 | カタログに要る分は `.storybook/preview.css` が `theme(static)` 付きで読み直す。本番の CSS へ付けると使っていない変数まで持つ (ADR-0056)                                                                                                                                                                                 | Storybook がトークンの一覧を CSSOM 以外から読むようになったら撤去                                |
| `@utility example-placeholder`                             | 生成物に無い                                                                                                                                                                             | `--placeholder` を当てる唯一の口。`@theme inline` へ通さないので、この utility を経由しない限り当てられない。`select` の実テキストから到達できないことが制約になる (ADR-0035)                                                                                                                                           | 上流が例示専用のトークンと当て口を持ったら撤去                                                   |
| `@utility scroll-area-focus-outline`                       | 生成物に無い                                                                                                                                                                             | ScrollArea の Viewport の focus 指標を Root の outline で代替する。当たる条件は `src/styles.css` の当該コメントが持つ                                                                                                                                                                                                   | 上流が Root 側の指標を持ったら撤去                                                               |
| `@layer base` の `@media (prefers-reduced-motion: reduce)` | 生成物に無い                                                                                                                                                                             | animation と transition の時間を詰める。上流の生成物は動きの抑制を持たない                                                                                                                                                                                                                                              | 上流が同じ既定を入れたら撤去                                                                     |

生成物に無い説明コメントは、単独の行を占めるものも含め、それが説明する乖離の行が持つ (light の `--placeholder` の直上のコメントは適用範囲の説明なので `--placeholder` の行)。
上表に独立した行を持つのは、説明する対象自体が乖離ではない `@theme inline` の直前の注記だけである。

## Consequences

- 乖離の行が増減するたびにこの ADR を更新する。行の増減は決定内容の変更ではないため、README 一覧の Date 欄は動かさない
- 許容リストへの行の足し忘れは `registry-baseline.test.ts` では鳴らない。突き合わせは ADR-0025 の手順で行う
