# registry からの乖離の台帳

shadcn registry の生成時 baseline (`docs/registry-baseline/`) から、このリポジトリが動かした行の一覧である。
乖離は生成時 baseline を交えた 3-way で判別し、この台帳の行に限る (ADR-0020)。行を足すか消すかの基準は ADR-0020「追加と削除の基準」、baseline との突き合わせの手順は `docs/guides/registry.md` にある。

- baseline とローカルの差分は、下の表と 1:1 で対応する。差分に対応する行が無ければ、足すか差分を戻す
- ローカルの実装が上流と同じ結果になったら、行を消す
- 行の増減は ADR-0020 の決定を変えないので、ADR は書き換えない
